# aut2fa-python

Biblioteca cliente (SDK) de Python para enviar, consultar e verificar códigos 2FA pela API aut2fa.

## Desenvolvimento do SDK

Este repositório contém a estrutura inicial. A implementação do cliente e a publicação no PyPI estão pendentes.

Consulte a [documentação da API aut2fa](https://doc.aut2fa.com) para acompanhar o contrato HTTP.
